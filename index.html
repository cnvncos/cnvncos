画饼清单
时段
「起始」不设 = 灰色待定，只在清单；只选到月 = 整个月；年月日都选 = 精确到那一天。「结束」不设 = 与起始相同（单月或单日）；选了则从起始到结束。
添加活动
左侧填名称和时段，点「添加待定计划（画饼+1）」；也可以点日历格子的空白处直接添加，能设连续天数和颜色。
拖动
↕ 上下拖动调整顺序；拖到日期格子 = 定为该天的活动；把日历上的活动拖回清单 = 转回待定。
颜色
灰 = 只在清单；紫 = 显示在指定月份顶部；日历上的活动可以自己选颜色。
条目按钮
星号按钮标星/取消标星；✎ 修改名称或时段；× 删除这一条。
排序与筛选
⇅ 可按时间或星标优先排序（标星的排最上方）；上方下拉可按月份筛选，类型可多选「待定」「已定」「标星」（满足任一即显示）。
日历其他
点日期数字可以高亮这一天，再点取消；日期旁的淡色小字是节日；删错了点「撤回上一步」。
显示范围与面板
顶部选起始月到结束月，最多 12 个月；拖面板右边缘调宽度、底边缘调高度。
保存
每次改动都会自动保存；点「存档」可以手动存一份，最多 20 份。

从备份恢复

选备份文件，或粘贴之前复制的备份文本。

一行一个计划，写全年月日按已定，其余按待定：
2027.3.11 展会 → 已定
2027.3-4 某活动 → 待定（带时段）
洛克-LOL → 待定（未定时段）

导出备份

.json 和 .txt 内容相同，都能用来完整恢复；可读清单也能导入，但只能还原活动名称与日期时段，颜色、星标、存档和设置不会恢复。

退出前要导出备份吗？

退出会清空本机全部计划数据。日常登录后会自动从云端恢复；若服务器出事，只能靠你手里导出的文件找回。

手动复制

浏览器不允许直接写入剪贴板，内容已全选，按 Ctrl+C 复制即可。
